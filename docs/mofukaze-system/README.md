# Mofukaze Blog 系统总览

Mofukaze Blog 是一个偏个人表达的 Nuxt + Node 多服务博客系统。它的核心不是传统 CMS 的管理面板，而是围绕“文章、收藏、关于、动态、背景音乐、主题氛围”组合出一个长期可维护的个人站。

## 服务组成

- `mofukaze/`：Nuxt 3 前端，负责页面、主题、编辑器、音乐播放器和 SSR。
- `api_gateway/`：Express API 网关，统一代理 `/api/*` 请求，并用 `ADMIN_TOKEN` 做单管理员写权限控制。
- `blog_service/`：H3 + Prisma 后端，承载文章、收藏、评论、访问统计、资源上传、关于页和动态页。
- `user_service/`：保留的用户服务，当前主站管理权限主要走网关的管理员令牌。
- `resource_service/resources/` 与 `/media`：历史资源目录和服务器媒体目录；当前图片、视频、音乐更偏向 `/media`。
- `mofukaze/nginx.conf`：生产入口与静态媒体映射。

## 内容模块

- 文章：长内容，支持标签、子标签、详情目录、评论、阅读统计和图片/视频富文本。
- 收藏：游戏、动漫、电影、音乐等个人收藏架，封面经过裁剪后上传。
- 关于：回忆录风格分段文本，仅管理员可添加，适合沉淀长期自述。
- 动态：轻量个人碎片流，复用关于页数据表，支持现有富文本编辑器和图片/视频上传。
- 背景音乐：读取云端音乐目录中的 `playlist.json`，面板关闭不打断播放，支持进度拖动和连播。
- 主题：星光、樱花、极光、午夜四套主题，用 CSS 变量驱动页面表面、文字、阴影和动态效果。

## 管理边界

只读接口默认公开，写操作需要通过 API 网关携带：

```http
Authorization: AdminToken <ADMIN_TOKEN>
```

前端通过 `useAdmin()` 保存 token、检测管理员状态，并控制写作入口、删除入口、关于/动态编辑入口的显示。

## 当前设计原则

- 资源上传走同一个 `/resource/upload`，按 `purpose` 区分文章图、收藏封面、视频、音乐。
- 关于页和动态页共用 `about_segment`，用 `kind = about | moment` 区分。
- 前端尽量使用全局主题变量，避免某个组件硬写白底或深色遮罩。
- 富文本内容由管理员写入，公开页面只负责展示。
