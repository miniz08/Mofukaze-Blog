# 维护建议与后续扩展

## 内容维护

- 长内容写在文章页，轻内容写在动态页。
- 关于页适合长期稳定的回忆录式内容，不建议承载频繁更新。
- 收藏页适合保留“我喜欢什么”的主题分区，后续可以把分类配置抽成可编辑数据。

## 视觉维护

新增页面时优先复用：

- `var(--surface-card)`
- `var(--surface-reading)`
- `var(--surface-soft)`
- `var(--border-soft)`
- `var(--theme-text)`
- `var(--theme-accent)`

避免固定 `rgba(0,0,0,0.8)` 这类强遮罩。星光和极光主题更适合通透表面，午夜主题可以保留更深的阅读背景。

## 资源维护

- 图片、视频、音乐都走统一上传服务。
- 管理员编辑器里如果出现 `blob:` 或 `data:`，说明上传还没有完成，不应该保存。
- 大视频可以直接上传到服务器，但仍建议控制单个文件大小，避免浏览器加载压力过大。

## 安全与权限

当前系统是“个人博客单管理员”模型：

- 写操作依赖 `ADMIN_TOKEN`。
- 评论等公开写入口由网关白名单放行。
- 管理员 token 应该通过环境变量配置，不建议提交到仓库。

如果未来需要多用户，可以再恢复或扩展 `user_service`，但当前单管理员方案更适合个人站。

## 可继续优化的方向

- 给动态页增加置顶、草稿、仅自己可见等状态。
- 给关于页增加编辑和拖拽排序。
- 给资源服务增加大小限制和后台资源清单。
- 给评论区增加审核队列和垃圾评论过滤。
- 把收藏分类从前端常量迁移为数据库配置。
- 给音乐播放器增加随机播放和歌词字段。
